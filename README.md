# SALF
Paper: Improving EEG-Based Depth of Anesthesia Classification in Non-Sensitive Patients Using Sensitivity-Aware Learning

Authors: Wei Tao, Tianqi Fang, Shengcai Duan, Yi Yang, David Holcman, Aiping Liu, Tzyy-Ping Jung, and Feng Wan.

Submitted to: IEEE Journal of Biomedical and Health Informatics (JBHI).

SALF is a sensitivity-aware learning framework for EEG-based depth-of-anesthesia classification that addresses inter-individual variability in anesthetic EEG responses. Through knowledge distillation, a teacher trained on EEG-defined sensitive subjects guides a student trained on non-sensitive subjects to distinguish awake, optimal anesthesia, and excessive anesthesia states. Evaluations on OBA, HBA, and VitalDB demonstrate improved mean classification accuracy in non-sensitive subjects across four backbone architectures.
